# 0.12.0.dev2 - Simpler Library Workflows

This testing preview makes the common tasks easier to find without changing your
existing source identities or enabling automatic imports.

- Six main pages: Libraries, Sources, Activity, Conflicts, Settings and Help.
- One Add files workflow for ordinary folders and combining collections.
- Import choices stay temporary unless you explicitly save the library's rules.
- Direct Folder rules, Reorganize files and Move library actions.
- Older laptop-folder profiles appear alongside other saved folders.
- Conflict-review files stay out of exports unless selected.
- Shorter README, refreshed screenshots and an updated PDF guide.

Windows and Linux source checks passed. This is not a confirmed fix for the
native 0.11.2 crashes. Clean installation, repair, uninstall and physical USB-drive
checks remain incomplete; see the validation notes. Keep independent backups.

The unsigned Windows installer is self-contained and can also repair, upgrade
or uninstall an existing installation. Network destinations still need to be
mounted and authenticated through the operating system.
