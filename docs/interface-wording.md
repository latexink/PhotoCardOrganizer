# Interface And Guide Conventions

Use a short name for each task and keep that name the same in the window,
confirmation and guide. Start instructions with the user's goal, then give the
steps. Put warnings beside the action they affect, rather than inside a long
feature description.

The six main pages are Libraries, Sources, Activity, Conflicts, Settings and Help.
Less common options sit under More or Advanced. A task opened from a page has a
clear route back. Library rules, default rules and one-time import rules must be
named separately so users know what saving will change.

## Reference

Sony's official camera help guides provide useful information-design examples:

- [How to use the Help Guide](https://helpguide.sony.net/ilc/2110/v1/en/contents/TP1000657876.html): task headings, a table of contents, related topics and a separate startup guide.
- [Using the MENU button](https://helpguide.sony.net/ilc/2110/v1/en/contents/TP1000640145.html): menus grouped by use, consistent group names and explicit navigation steps.
- [Main menu](https://helpguide.sony.net/ilc/2110/v1/en/contents/TP1002102430.html): related settings reviewed together, with photo and movie contexts distinguished.

These are references for structure and clarity, not a template for Sony branding.
Photo Card Organizer keeps its own graphite-and-jade theme, icons and wording.
